## Why this file exists

The Stage 00 specification requires that the project record its licensing
position explicitly rather than defaulting silently. Recording "all rights
reserved" is a statement of fact about the current state, not a recommendation
against open-sourcing the project later.

If the owner later selects a license, that decision should add a `LICENSE` file,
set the `license` field in `pyproject.toml`, and update this document. Until
then, tooling must not assert a license identifier it has not been given.

## Third-party dependencies

Dependencies retain their own licenses. This policy governs only QCF's own
source, documentation, and configuration.
