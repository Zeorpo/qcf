# ADR-NNNN: <decision in a short noun phrase>

- **Status:** Proposed | Accepted | Superseded by ADR-NNNN | Rejected
- **Date:** YYYY-MM-DD
- **Stage:** NN

## Context

The forces that made a decision necessary. What was true before, what pressure
exists, and what would go wrong if nothing were decided.

## Decision

What was decided, stated so that a reviewer can check the code against it.

## Alternatives considered

What was rejected, and why. An ADR with no alternatives is a description, not a
decision.

## Consequences

What this makes easy, what it makes hard, and what it makes impossible later.
Include the costs; an ADR listing only benefits has not been thought through.

## Verification

How a reviewer confirms the implementation matches this decision. Name the test,
the check, or the command. **Required** — a decision nobody can check has been
asserted, not recorded.
